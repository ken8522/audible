Turn an audiobook into text

Three steps to convert an .m4b (or .mp3 / .m4a) that plays in VLC into a readable text file — right on your own PC.

1

Get the latest version

Open PowerShell (Start button → type PowerShell → Enter). Paste these two lines, pressing Enter after each:

cd -LiteralPath "C:\Users\ken77\Ken\[] BUSINESS IDEAS\28 Claude Coding Project\Audible To Text" git pull

Keep the -LiteralPath part — without it, PowerShell misreads the [] in your folder name.

2

Convert your audiobook

Type this much — with a space at the end — but don’t press Enter yet:

python -m aax2text.cli convert
◆ The trick that saves typing

Drag your .m4b file from File Explorer straight into the PowerShell window. It fills in the long file path for you automatically.

Then type the rest and press Enter:

--model small --out .\out

All together, the finished line looks like this:

python -m aax2text.cli convert "…\Nonviolent Communication [B072LG72D3]\book.m4b" --model small --out .\out
3

Open your text file

It works for a while (a progress bar shows how it’s going). When it finishes, your transcript — split by chapter — is waiting here:

C:\…\Audible To Text\out\Nonviolent Communication.txt

Open it in Notepad, Word, or anything else.

Good to know

  • VLC yes, Media Player no? That’s normal — Windows Media Player just can’t read this file type. It does not mean it’s locked.
  • Only opens in the Audible app? Then it is still locked — unlock it first (the AAX steps in the README).
  • First run needs internet for a few minutes to download a small “listening” helper. After that it runs offline.
  • Rather click than type? Run python -m aax2text.cli gui to do it all in your browser.

First-time setup — you’ve already done this once

If you ever start fresh on another PC, install these first (each is a one-time step):
  1. Install Python from python.org — tick “Add Python to PATH” during install.
  2. Install FFmpeg: winget install Gyan.FFmpeg
  3. Download the program: git clone -b claude/aax-text-transcription-6p72vy https://github.com/ken8522/audible.git "…\Audible To Text"
  4. Install its helpers (from that folder): pip install -e ".[gui]"
